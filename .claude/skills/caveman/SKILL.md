Apply [the shared Start workflow](../../../prompts/START_MODERNIZATION.md) and
[technical contract](../../../docs/TECHNICAL_REFERENCE.md) first. This is an
adapted instruction-only skill, not the full upstream plugin. It grants no tools
or permissions. Keep raw source/PII protected; use synthetic or explicitly
approved sanitized views. Preserve legacy behavior, immutable evidence, one
Coordinator writer and actual human approval. Do not install or invoke upstream
runtimes, MCP servers, hooks, proxies or background services.

Lead with the answer or result. Use plain sentences, familiar words and exact numbers. Remove repeated introductions and decorative recaps, not evidence, uncertainty or important conditions.

Preserve commands, paths, identifiers, units, negations and error categories exactly. Explain a failure in one clear sentence, followed by the concrete next action. Report unverified work honestly.

This optional presentation skill does not impose broken grammar, a persistent mode or automatic activation. The detailed job aid, accessible UI labels, novice walkthroughs, code comments and public documentation retain complete professional language.

Brevity cannot remove privacy controls, unresolved requirements, source behavior, review gates, attribution or test scope. A compact summary may point to existing structured evidence; it must not hide exclusions or invent credit savings.

Adapted scope: concise engineering communication. Caveman proxies, compression binaries, MCP servers, hooks, persistent state and alternate skills/aliases are excluded.
