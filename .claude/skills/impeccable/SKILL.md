Follow [AGENTS.md](../../../AGENTS.md) and the
[technical contract](../../../docs/TECHNICAL_REFERENCE.md) first. The foreground
Coordinator agent owns integration through `modernize-process`,
`validate-program` and `consult-modernization`; load this optional skill only
when relevant. This adapted
instruction-only skill grants no tools or permissions. Keep raw source/PII
protected; use synthetic or explicitly approved sanitized views. Preserve legacy
behavior, immutable evidence and authentic human business-review decisions.
Keep discovery read-only and obey the configured access and review policy. Do
not install or invoke upstream runtimes, MCP servers, hooks, proxies or
background services.

Choose the surface purpose: Operate for setup, requirements and gap filters; Read for guides and report detail. Successful task completion and readable evidence outrank expressive decoration.

Inspect the current rendered surface, existing tokens and relevant operator instructions before editing. Preserve its identity and factual copy during refinement. A redesign does not authorize fabricated metrics or altered source behavior.

Build hierarchy with restrained spacing, clear headings, readable type and consistent components. Use status labels as well as color. Make intentionally retired, unknown, source-derived and observed-parity states unmistakable. Keep current totals visible while detailed code/test evidence expands on demand.

Check keyboard focus, dialog close/return, viewport/zoom reflow, long content, empty/loading/error states, contrast and reduced motion with synthetic data. Batch findings, fix the supported causes and confirm the changed surface. Stop bounded polishing once criteria pass; run another pass only for a new issue.

Record actual browser/host/build evidence and unresolved accessibility criteria. No aesthetic score or static scan proves complete WCAG, Windows or Wells Fargo approval.

Adapted scope: Operate/Read design and bounded audit. Upstream binary launcher, downloads, scripts, new PRODUCT/DESIGN files and global permission claims are excluded.
