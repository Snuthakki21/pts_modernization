# PTS Modernization Workbench

This repository contains the local mainframe modernization workbench, its process workflow, synthetic test harness and supporting evidence. Start with [START_HERE.md](START_HERE.md) for setup and the guided UI, then use [prompts/START_MODERNIZATION.md](prompts/START_MODERNIZATION.md) with GitHub Copilot Chat or Claude Code.

The non-production target is Python and SQLite. Conversion credit requires source-to-target coverage and test evidence. Supply approved mainframe and Db2 configuration locally; no credentials or operational source are included here.

The [executive report](docs/executive-report.html) distinguishes the user-reported estate baseline from observed and verified process counts.
